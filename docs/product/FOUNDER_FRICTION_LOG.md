# Founder Friction Log

Required by DEC-GATE-H1-001. One line per incident, at the moment it happens or same evening. The log matters more than the capture count — a day with zero captures and three friction entries is a *good* data day.

Format:

```
YYYY-MM-DD | JOB | type | note
```

Types: `chose-not-to-record` · `started-then-abandoned` · `correction-too-hard` · `wrong-job` · `wrong-person-trade-location` · `confirmation-fatigue` · `memory-was-easier` · `other`
